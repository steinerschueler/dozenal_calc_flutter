## Beschreibung · Description (max. 4000, genutzt 1142, reiner Text)
```
一款「十二進位計算機」——一台不以十、而以十二為基底運算的科學計算機。並配有專屬的數字符號。

十二進位能做到、十進位做不到的事

在十進位中，1/3 是無限循環小數（0,333…）。在十二進位中，它既簡短又精確：0,4。六分之一、九分之一，以及所有分母由二和三組成的分數，在十二進位下都會成為有限小數。這並非偶然：十二有六個因數，十只有四個。

Dozenal Calc 精確運算——一條有理數軌道與浮點運算並行執行。循環小數會在重複的數字上方標以橫線，例如 1/7 顯示為 0,186A3，並帶有循環節橫線。

功能範圍

• 四則運算、括號、正負號
• 乘冪、平方根、n 次方根、任意底數的對數
• 三角函數與雙曲函數及其反函數
• 常數 π、e、φ、√2；階乘、絕對值、倒數、取模
• 並聯加法（a⊕b），用於電阻電路
• 記憶體（STO/RCL/MC），精確保留有理數
• 角度模式 DEG / RAD / GRAD
• 輸入「與」結果皆可在十二進位／十進位之間切換，並自動換算

單位換算器

第二種計算模式可在英制／十二進位單位與公制單位之間互相換算——長度、面積、體積、重量、時間、角度、貨幣（£/sh/d）與溫度。新增：角度區段中的百分比坡度（0–90°）。

可親手體驗的理論——現在配有圖片

一份圖文並茂的讀本，分三個篇章解釋為何「十二」是一個特別的數字：
• 十二與世界——從十二邊形與正十二面體，到黃鐵礦、石榴石、病毒與準晶體，再到音樂、藝術、建築與曆法
• 十二進位數學——因數與循環節、各種數字基底的比較，以及位值制的歷史
• 十二進位社會——推動十二進位的運動、為十和十一設計的新數字、TGM 度量系統與相關的十二進位計算機

許多章節現在展示公共領域的歷史插圖——從 Haüy 的黃鐵礦圖版、Leonardo 的正十二面體，到 Vermeer 的天秤——每一幅皆附有可點按的出處資訊。另外還有一套關於度量與數字的專屬單位理論。
```
