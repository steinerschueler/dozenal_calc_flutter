## Beschreibung · Description (max. 4000, genutzt 1384, reiner Text)
```
「十二進計算機（Dozenalrechner）」——10進ではなく12進で計算する科学計算機です。数字には独自の記号を使います。

12進にできて10進にできないこと

10進法では 1/3 は無限に続く循環小数です（0,333…）。12進法では短く、しかも正確です：0,4。6分の1や9分の1、そして分母が2と3だけからなるすべての分数も、12進では有限になります。これは偶然ではありません。12には約数が6つあり、10には4つしかないからです。

Dozenal Calc は正確に計算します——有理数トラックが浮動小数点演算と並行して動きます。循環小数は、繰り返される数字の上に線を引いて表示されます。たとえば 1/7 は 0,186A3 として、循環節を示す線とともに表示されます。

機能一覧

• 四則演算、括弧、符号
• べき乗、平方根、n乗根、任意の底の対数
• 三角関数と双曲線関数、およびそれらの逆関数
• 定数 π、e、φ、√2；階乗、絶対値、逆数、剰余
• 並列加算（a⊕b）——抵抗回路の計算に
• メモリ（STO/RCL/MC）、有理数を正確に保持
• 角度モード DEG / RAD / GRAD
• 入力にも結果にも使える 12進/10進 の切り替え、自動換算つき

単位換算機

第二の計算モードでは、ヤード・ポンド法／十二進系の単位とメートル法の単位を相互に換算できます——長さ、面積、体積、重さ、時間、角度、通貨（£/sh/d）、そして温度。新機能：角度の分野で、勾配をパーセント表示（0〜90°）。

手で触れる理論——いまや図版つき

豊富な図版を添えた読み物が、なぜ12という数が特別なのかを、3つのブロックで解説します：
• 十二と世界——十二角形や正十二面体から、黄鉄鉱、ザクロ石、ウイルス、準結晶を経て、音楽、芸術、建築、暦まで
• 十二進の数学——約数と循環節、数のさまざまな基数の比較、位取り記数法の歴史
• 十二進の社会——十二をめぐる運動、10と11のための新しい数字、計量体系 TGM、そして関連する十二進計算機

多くの章には、いまやパブリックドメインの歴史的な図版が掲載されています——アユイの黄鉄鉱の図版から、レオナルドの正十二面体、フェルメールの天秤まで——それぞれにタップできる出典表示つき。さらに、計量と数についての独自の単位理論も。
```
