## Beschreibung · Description (max. 4000, genutzt 1145, reiner Text)
```
一款"十二进制计算器"——一种科学计算器,它不以十为底,而以十二为底进行运算。并配有专属的数字符号。

十二进制能做到、十进制做不到的事

在十进制中,1/3 是一个无限循环小数(0.333…)。而在十二进制中,它简短又精确:0.4。同样,六分之一、九分之一,以及所有分母仅由二和三构成的分数,在十二进制下都会变成有限小数。这并非偶然:十二有六个约数,而十只有四个。

Dozenal Calc 进行精确运算——一条有理数轨道与浮点运算并行运行。循环小数会在重复的数字上方加横线显示,例如 1/7 显示为 0.186A3,并标注循环节横线。

功能范围

• 四则运算、括号、正负号
• 乘方、平方根、n 次方根、任意底数的对数
• 三角函数与双曲函数及其反函数
• 常数 π、e、φ、√2;阶乘、绝对值、倒数、取模
• 并联加法(a⊕b),用于电阻电路计算
• 存储器(STO/RCL/MC),精确保留有理数
• 角度模式 DEG / RAD / GRAD
• 输入和结果均可在十二进制/十进制之间切换,并自动换算

单位换算器

第二种计算模式可在英制/十二进制单位与公制单位之间相互换算——长度、面积、体积、重量、时间、角度、货币(£/sh/d)以及温度。新增:角度区间内的百分比坡度(0–90°)。

可触可感的理论——现已配图

一篇图文丰富的读物分三个板块,解释为什么十二恰恰是一个特别的数字:

• 十二与世界——从十二边形、十二面体,到黄铁矿、石榴石、病毒与准晶体,再到音乐、艺术、建筑与历法
• 十二进制数学——约数与循环节、各数基的比较、一部位值制的历史
• 十二进制社会——倡导十二的运动、为十和十一设计的新数字、TGM 度量系统以及相关的十二进制计算器

许多章节现在展示公有领域的历史插图——从阿羽依的黄铁矿图版,到达·芬奇的十二面体,再到维米尔的天平——每幅均附有可点按的出处说明。此外还配有一篇关于度量与数字的专属单位理论。
```
