A "dozenal calculator" — a scientific calculator that counts not in ten, but in twelve. With its own symbols for the digits.

<b>What base 12 can do that base 10 cannot</b>

In decimal, 1/3 is an infinite repeating fraction (0.333…). In base 12 it is short and exact: 0.4. Sixths, ninths, and every fraction whose denominator is built from twos and threes become finite in dozenal. This is no accident: twelve has six divisors, ten only four.

Dozenal Calc runs an exact rational track in parallel with ordinary floating-point arithmetic. Repeating fractions are shown with a bar over the repeating digits, just as taught in school. Example: 1/7 appears as 0.186A3 with a period bar, followed by raised dots when the period exceeds five digits.

<b>Feature set</b>

• Basic arithmetic + parentheses + signs
• Power, square root, nth root
• Logarithm to any base
• Parallel addition (a⊕b = ab/(a+b)) — useful for resistor circuits
• Trigonometry (sin, cos, tan, cot) and their inverses
• Hyperbolic functions (sinh, cosh, tanh, coth) and their inverses
• Constants π, e, φ, √2
• Factorial, absolute value, reciprocal, modulo
• Memory (STO/RCL/MC) with exact rational round-trip preservation
• Angle modes DEG / RAD / GRAD (default: DEG)
• Double-tap function keys switch to the inverse (sin → sin⁻¹)
• Doz/Dec switch: input AND result in base 12 or base 10, with automatic conversion of the currently visible number on switch
• First-launch operating intro: eight explanatory images with an interactive decoder page placing glyphs and familiar numbers side by side — re-openable any time via the (?) button
• Conversion page: live conversion of the input value into classic twelve-based units (inches/feet, pence/shillings/pounds, dozen/gross/great gross, seconds/minutes/hours, fractions of 360°), shown in both base 10 and base 12
• Fourteen languages with a picker in the info menu: Deutsch, English, Français, Español, Italiano, فارسی, Русский, Gaeilge, हिन्दी, 简体中文, 繁體中文, Cymraeg, 日本語, العربية

<b>What Dozenal Calc does not do</b>

• No ads
• No tracking
• No analytics
• No internet connection
• No permissions — the app requests no camera, microphone, location, storage, or any other access
• No personal data

The app works completely offline. What you type stays on your device.

<b>Who is it for?</b>

For teachers who want to show how a different number system would change everyday fraction arithmetic. For students who want to see their mathematics from an unfamiliar perspective.
